## 표시 읽는 법

- 표시 없음: 시험 범위 내용
- 📎 교과서 밖 / 점선 상자: 이해를 돕는 참고 자료
- 🎓 고등 과정 심화: 접혀 있음, 필요할 때만 펼치기
